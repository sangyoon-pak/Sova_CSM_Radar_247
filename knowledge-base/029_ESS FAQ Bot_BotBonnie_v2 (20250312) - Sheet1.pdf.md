What would be the reason for giveaway prizes' information cannot be updated after prize distribution for BotBonine? 
1. System Limitation: Due to system constraints, if a prize is changed during an ongoing campaign, the prize name cannot be updated in real-time. As a result, updates may only take effect the following day (this is not a bug). If a prize needs to be changed during an active campaign, we recommend creating a new prize instead of modifying the existing one. 
2. Prize Modification Process: Already issued prizes will not be updated. The product team has designed this behavior because unexpected prize changes could lead to a high volume of customer complaints. Therefore, only prizes issued after the modification will reflect the change. We strongly recommend that if a prize needs to be changed mid-campaign, a new package with the updated prize should be created instead. (This is because the prize distribution kit allows only one type of prize per setting, and modifying the original configuration is not advised.)

"Read users" is only available for LINE mass braodcast while otehr broadcast types do not have the read data due to messaging API limitation. For more details, please check up on our Resource Center's article: https://docs. botbonnie.appier.com/docs/broadcasts#report-summary

Currently you can check for the user numbers who has a certain tag on them and utilize this as a filter to view and to do reatrgeting. You can also check the last time a tag was added to a user and the number of times the tag was added, enabling further analysis. For further analysis, This is planned for a future release. What channels does BotBonnie support? BotBonnie supports multiple platforms, including LINE, Facebook, Instagram, WebChat, WhatsApp, KakaoTalk, Zalo and Viber. 
Can I connect multiple channels to one BotBonnie chatbot? 
Yes, clients can connect multiple social media accounts to one BotBonnie chatbot or several BotBonnie chatbots but it's suggested to confirm with their scenario first. If the client wants to provide the same conversaiton within all accounts, the client can link to one BotBonnie chatbot which will only cost for 1 chatbot platform fee. If the client wants to provide different conversations corresponding to the different accounts, the client should link each account to each BotBonnie chatbot and pay for several chatbot platform fee. 
Can Knowledge bot recommend products to users? 
No, BotBonnie's AI Knowledge Bot cannot recommend products to clients. It is used to train data for asnwering client's inquiries. For the product recommendation related functions, it would be AI Salesbot's function.
