Getting Started with BotBonnie [0]

https://docs.botbonnie.appier.com/docs/getting-started-with-botbonnie



BotBonnie, by Appier, is an omnichannel chatbot platform designed to streamline your marketing efforts and enhance customer engagement through conversational marketing. BotBonnie integrates seamlessly with various platforms to deliver consistent and personalized interactions. Whether you aim to boost sales, improve customer service, or gather valuable insights, BotBonnie is here to simplify and optimize your processes. Use BotBonnie for:

Conversational marketing

Automated customer service

Comprehensive customer segmentation

Analytics and reporting

Utilize BotBonnie's intuitive drag-and-drop interface to design your chatbot. You can create messages using various formats such as text, images, videos, and carousels.

Customize campaigns using an array of pre-built gamified marketing tools such as daily check-ins, lucky draws, scratch-off cards, and member-get-member programs to engage interactions.

👍TipAutomate activity rewards, dynamic discount codes, and coupons to incentivize engagement and drive conversions. Use BotBonnie's advanced kits to easily manage sweepstakes, follower acquisition, surveys, and invoice registration to boost participation and grow your audience.

BotBonnie supports integrations with your business's social media and messaging accounts including LINE, Facebook Messenger, Instagram, WhatsApp, KakaoTalk, Viber, and Zalo.

In addition, you can connect to your e-commerce platforms of choice, including Shopify, Shopline, 91 APP, and Cyberbiz, to send notifications for post-purchase journeys.

👍TipConnect multiple LINE accounts and Facebook pages to a single bot to streamline operations and centralize communication. Filter customer support conversations by user nickname, tags, and message types, and respond to them on mobile just like chatting with friends for a more personal touch.

Configure proactive chat prompts to start conversations with visitors at the right moment, reducing bounce rates and encouraging conversions.

Users who click on this button will be redirected to Facebook, where they can share the Facebook post with the message content you configured:

Go to your chatbot flows and add a button to one of your messages. From the On click dropdown menu in the button settings, select Share on Facebook.

In the modal that appears, configure the Shared URL and set the Action after sharing.

Shared URL: The URL to be shared in the Facebook post.

Action after sharing: The action to be executed after the user finishes sharing the post.

Postback module: Send a module in the chat.

Open URL: Redirect the user to a specific URL.

Next, provide the content for the Facebook post, such as the posts hashtag, title, and subtitle.

Hashtag: Must not exceed 20 characters.

Image: File size must not exceed 1 MB. Supported file formats: PNG, JPEG, GIF. To prevent the image from being cropped, we recommend using an aspect ratio of 1.91:1.

Title: Must be 3 to 80 characters.

Subtitle: Must not exceed 100 characters.

Click Close, then deploy your changes.

## Overview

> 👍 Supported platforms

>

> - LINE

Image carousel messages display a series of cards in a horizontally scrollable format, where each card can contain an image with a button or customizable interactive action regions.

Note that image carousel messages differ from standard [carousel](doc:message-type-carousel) messages. To learn more about which message type is more suitable for your use case, see the [image carousel vs carousel](#image-carousel-vs-carousel) comparison table.

## Creating an image carousel

Click **Add module**, then select **Image carousel**. There are two options for image carousel types; refer to the following sections for setup instructions:

- [**Images**](#images): Each card can contain a single [button](doc:button).

- [**Full-card carousel image with custom button area**](#full-card-carousel-image-with-custom-button-area): Fully customize the interactive layout of the card by adding action regions. Each card can have multiple action regions, and each action region can be configured with on-click actions and triggered actions.

## Managing image carousel cards

### Adding cards

To add a carousel card, click the **+** icon to the right of the last card of the carousel.

![](https://files.readme.io/d93c498-image-carousel-add.gif "image-carousel-add.gif")

After adding multiple cards, you'll be able to navigate to the edit screens of each carousel card by clicking the arrows on the left and right of the settings window.

![](https://files.readme.io/63ad9de-image-carousel-navigate.gif "image-carousel-navigate.gif")

### Changing card sequence

To change the sequence of a carousel card, click and drag the colored box below the card. The gray boxes represent the other cards in the carousel—use these as a reference to reposition the current card (the colored box) into the desired position in the sequence.

![](https://files.readme.io/5a4437d-image-carousel-reposition.gif "image-carousel-reposition.gif")

### Deleting cards and deleting the carousel

To delete a single carousel card or the entire carousel message, click the delete icon and select one of the following options:

Video files can be hosted via FTP, Dropbox, or Google Drive, and downloads must be allowed.

Dropbox and Google Drive file URLs must be modified before being added to the module.

🚧Unsupported video URLsVideo files on hosting and streaming services not listed above, e.g. YouTube, are not supported.

Before inputting the Dropbox file URL in your bot settings, complete the following steps:

Retrieve the file ID. The file ID is the string located between https://drive.google.com/file/d/ and /view?usp=sharing.

Append the file ID to the following URL: https://drive.google.com/uc?export=download&id=.

For example:

Original: https://drive.google.com/file/d/FILE_ID/view?usp=sharing

Modified: https://drive.google.com/uc?export=download&id=FILE_ID

Before inputting the Dropbox file URL in your bot settings, replace the "www" in the Dropbox file URL with "dl". For example:

Original: http://www.dropbox.com/s/qwertyuiop/MY_VIDEO_FILE.mp4

Modified: http://dl.dropbox.com/s/qwertyuiop/MY_VIDEO_FILE.mp4
